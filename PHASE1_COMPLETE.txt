                    🚀 JAK URUCHOMIĆ
═══════════════════════════════════════════════════════════════

KROK 1: Zainstaluj dependencies
  $ pip install -r requirements.txt

KROK 2: Utwórz bazę PostgreSQL
  $ sudo -u postgres psql
  # CREATE DATABASE kit3_db;

KROK 3: Skonfiguruj .env
  $ cp .env.example .env
  Edytuj: DATABASE_URL=postgresql://localhost/kit3_db

KROK 4: Inicjalizuj
  $ python init_db.py
  (tworzy tabele, dodaje skills, tworzy admina i/użytkownika)

KROK 5: Uruchom
  $ python run.py

KROK 6: Otwórz przeglądarkę
  → http://localhost:5000

Logowania:
  Admin:    admin / admin123
  Użytkownik: technolog / technolog123
